# Tuyau Integration

Girouette fully supports [Tuyau](https://tuyau.dev), AdonisJS's type-safe API client generator. This integration gives you end-to-end type safety from your backend routes to your frontend API calls.

## What is Tuyau?

Tuyau is a type-safe API client for AdonisJS that:

- **Generates TypeScript types** from your routes and validators
- **Provides autocomplete** for route names and parameters
- **Infers request/response types** automatically
- **Catches type errors** at compile time

## Setup

<Steps>
  <Step>
    ### Install Tuyau

    If you haven't already, install Tuyau in your AdonisJS project:

    ```bash
    node ace add @tuyau/core
    ```
  </Step>

  <Step>
    ### Register the Girouette Hook

    Add the `generateGirouetteRoutes` hook to your `adonisrc.ts` **before** the Tuyau `generateRegistry` hook:

    ```typescript title="adonisrc.ts"
    import { defineConfig } from '@adonisjs/core/app'
    import { generateRegistry } from '@tuyau/core/hooks'
    import { generateGirouetteRoutes } from '@adonisjs-community/girouette/hooks'

    export default defineConfig({
      hooks: {
        init: [
          generateGirouetteRoutes(), // Register Girouette routes FIRST
          generateRegistry(),         // Then generate Tuyau types
        ],
      },
      providers: [
        // ... other providers
        () => import('@adonisjs-community/girouette/girouette_provider'),
      ],
    })
    ```
  </Step>

  <Step>
    ### Start the Dev Server

    Run your development server to trigger type generation:

    ```bash
    node ace serve --watch
    ```
  </Step>
</Steps>

<Callout type="warn">
  The order matters! `generateGirouetteRoutes()` must come **before** `generateRegistry()`
  so that routes are registered before Tuyau scans them.
</Callout>

## How It Works

### During Development

1. The dev server child process initializes the AdonisJS application
2. The `GirouetteProvider` scans your controllers and registers routes
3. Tuyau's `routesScanning` hook finds all registered routes
4. Tuyau analyzes routes and generates TypeScript types

### At Runtime

The same routes registered by the provider handle incoming requests normally.

### Type Generation

Girouette routes are included in Tuyau's generated types:

```typescript
// .adonisjs/client/registry/schema.d.ts
'posts.store': {
  methods: ["POST"]
  pattern: '/posts'
  types: {
    body: ExtractBody<InferInput<typeof createPostValidator>>
    response: Awaited<ReturnType<PostsController['store']>>
  }
}
```

## Example Usage

### Controller with Validator

```typescript title="app/controllers/posts_controller.ts"
import { Post, Get, Middleware } from '@adonisjs-community/girouette'
import { createPostValidator, updatePostValidator } from '#validators/post'
import { HttpContext } from '@adonisjs/core/http'
import { middleware } from '#start/kernel'
import PostModel from '#models/post'

export default class PostsController {
  @Get('/posts', 'posts.index')
  async index() {
    return PostModel.all()
  }

  @Get('/posts/:id', 'posts.show')
  async show({ params }: HttpContext) {
    return PostModel.findOrFail(params.id)
  }

  @Post('/posts', 'posts.store')
  @Middleware([middleware.auth()])
  async store({ request, auth }: HttpContext) {
    const data = await request.validateUsing(createPostValidator)
    return auth.user!.related('posts').create(data)
  }
}
```

### Validator

```typescript title="app/validators/post.ts"
import vine from '@vinejs/vine'

export const createPostValidator = vine.compile(
  vine.object({
    title: vine.string().minLength(3).maxLength(255),
    content: vine.string().minLength(10),
    published: vine.boolean().optional(),
  })
)
```

### Frontend Usage

```typescript title="frontend/api.ts"
import { createTuyau } from '@tuyau/client'
import type { Api } from '@your-app/.adonisjs/client'

const tuyau = createTuyau<Api>({
  baseUrl: 'http://localhost:3333',
})

// Full type safety and autocomplete
const posts = await tuyau.posts.index.$get()

// Request body is typed from validator
const newPost = await tuyau.posts.store.$post({
  title: 'My Post',      // ✓ Required, string
  content: 'Content...',  // ✓ Required, string
  published: true,        // ✓ Optional, boolean
})

// Type error: missing required field
const invalid = await tuyau.posts.store.$post({
  title: 'My Post',
  // ✗ Error: 'content' is required
})
```

## Type Inference

Tuyau infers types from:

### Request Body

Types are inferred from VineJS validators used with `request.validateUsing()`:

```typescript
@Post('/users')
async store({ request }: HttpContext) {
  // Tuyau infers body type from createUserValidator
  const data = await request.validateUsing(createUserValidator)
  return User.create(data)
}
```

### Response Type

Types are inferred from the controller method's return type:

```typescript
@Get('/users/:id')
async show({ params }: HttpContext) {
  // Tuyau infers response type as User model
  return User.findOrFail(params.id)
}
```

### Route Parameters

Parameters are inferred from the route pattern:

```typescript
@Get('/users/:userId/posts/:postId')
async show({ params }: HttpContext) {
  // Tuyau knows about userId and postId parameters
}
```

## Benefits

| Feature | Without Tuyau | With Tuyau |
|---------|---------------|------------|
| Route names | Strings, typos possible | Autocomplete, type-checked |
| Request body | Manual typing | Inferred from validators |
| Response type | Unknown | Inferred from return type |
| Parameters | Manual handling | Type-safe access |
| Refactoring | Manual updates | Compiler catches issues |

## Troubleshooting

### Types Not Generating

1. Ensure hooks are in the correct order in `adonisrc.ts`
2. Restart the dev server after configuration changes
3. Check that your controller files match the `controllersGlob` pattern

### Route Names Not Found

Make sure to name your routes:

```typescript
// ✗ No name - won't be in Tuyau types
@Get('/users')
async index() {}

// ✓ Named - will be in Tuyau types
@Get('/users', 'users.index')
async index() {}
```

### Validator Types Not Inferred

Ensure you're using `validateUsing` with a compiled validator:

```typescript
// ✓ Correct: Using compiled validator
const data = await request.validateUsing(createUserValidator)

// ✗ Won't work: Inline validation
const data = await request.validate({
  schema: vine.object({ name: vine.string() })
})
```
